# Decisões de projeto

Este diretório registra as decisões de arquitetura e design do `pos-install-linux`.

Cada arquivo documenta uma decisão. O estilo segue o espírito do ASD-STE100:

- Frases curtas (no máximo 20 palavras).
- Uma ideia por frase.
- Voz ativa.
- Um termo para cada coisa.
- Sem introdução nem conclusão.
